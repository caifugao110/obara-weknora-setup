## 5. 答复约束提示词要点

提示词文件：[`02-answer-prompt/welding-gun-selection-prompt.md`](02-answer-prompt/welding-gun-selection-prompt.md)

核心约束：
- **角色**：焊枪选型系统，从文档中筛选符合需求的焊枪图号
- **文档路由**：C 枪 → 3 个 C 文件；X 枪 → 3 个 X 文件
- **模糊范围**：压力 ±500、偏心 ±20、喉深/喉宽 ±50
- **输出格式**：仅输出图号，逗号分隔；未找到则输出「未找到符合要求的焊枪」
- **禁止**：编造数据、输出无关内容、使用函数调用格式

## 6. 阶段六使用说明

### 6.1 创建知识库并导入文档

1. 以超级管理员登录 WeKnora，进入「设计规范知识库」页面（或新建知识库）。
2. 导入 `01-knowledge-files/` 下的 **6 个 Excel 文件**。
3. 等待解析、切片、向量化完成（18,701 行数据，建议使用 `bge-m3` Embedding）。

### 6.2 配置答复约束提示词

1. 进入知识库的「答复约束提示词」面板。
2. 将 [`02-answer-prompt/welding-gun-selection-prompt.md`](02-answer-prompt/welding-gun-selection-prompt.md) 的全部内容粘贴到输入框，保存。
3. 保存后后端会创建/更新受管自定义智能体，后续问答均遵循该约束。

> 前置条件：该知识库所属工作空间已配置可用的 KnowledgeQA 问答模型（如 `deepseek-flash`），否则保存返回 `503 WEKNORA_NO_QA_MODEL`。

### 6.3 验证要点（阶段六验收）

- [ ] 6 个 Excel 全部解析成功，行数与上表一致
- [ ] C 枪提问只命中 C 文件图号，X 枪提问只命中 X 文件图号
- [ ] 模糊范围生效：喉深/喉宽 ±50、压力 ±500、偏心 ±20
- [ ] 变压器模糊匹配：输入「85」能命中 ITS85，输入「DB6」能命中 DB6/DB6-100R1
- [ ] 输出格式合规：仅图号逗号分隔，或「未找到符合要求的焊枪」
- [ ] 无编造数据（图号均来自文档）
